    接口示例

    同一个后端就是浏览器里这张页面的数据来源。

    # 创建（A/B 分流）
curl -X POST http://127.0.0.1:8787/api/links \
  -H "Content-Type: application/json" \
  -d '{"url":"https://a.example.com","variants":[{"url":"https://a.example.com","weight":1},{"url":"https://b.example.com","weight":1}]}'

# 看统计
curl http://127.0.0.1:8787/api/links/<slug>/stats
